#  AI Text-to-Voice Converter

An AI-powered Text-to-Speech (TTS) application that converts text into natural-sounding voice in **25+ languages** with multiple voice options and downloadable audio output.

---

##  About the Project

AI Text-to-Voice Converter is a multilingual Text-to-Speech system that allows users to:

- Convert text into speech
- Choose from 25+ languages
- Select different voice types (Male/Female/Accent-based)
- Download the generated audio file

This project is designed for accessibility, content creation,business marketing, education, and assistive technology applications.

## How It Works

- User enters text.
- Selects desired language.
- Chooses voice type.
- Clicks "Convert".
- AI generates speech.
- User can play or download the audio file.
